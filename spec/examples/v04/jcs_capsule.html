JCS Capsule Fixture (0.4 line)

What this fixture proves

This capsule declares spec_version: "0.4.0", so its integrity hash is computed with recipe v2 — RFC 8785, the JSON Canonicalization Scheme. Its data block carries numbers that canonicalize differently under the two recipes, which means the declared hash verifies only if the validator selects the recipe from the declared line. A validator that applied the legacy recipe here would compute a different digest and report a mismatch.
