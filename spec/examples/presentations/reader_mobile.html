Reader View

The mobile view is declared because it is an intentional capsule-owned surface. A host should not invent mobile presentation status just because responsive CSS exists; responsive CSS is ordinary styling.

This fixture keeps the full meaning in the root while also exposing a compact mobile entry for consumers that support it.
