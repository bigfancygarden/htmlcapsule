Reader And Print Letter Fixture

Reader View

The reader presentation is the canonical human-readable artifact. It summarizes the fixture and points to a print-letter presentation that is explicitly declared rather than inferred from CSS media rules.

Because both views share this same document, a custody app can list the declared print view while keeping its own source and safe-preview tools separate.

Letter View

This section is the print-letter entry. It is suitable for printing, but it remains ordinary HTML in the same capsule file and is discoverable from the manifest.
