Sealed Sources Warn-Shape Fixture

What this demonstrates

This capsule declares sealed_sources as an array of source keys instead of an object mapping source keys to resolved payloads. That defeats the convention's purpose — a list of keys carries no data to re-resolve from — so the validator warns on the shape (spec 4.1.2). The capsule remains otherwise valid: the convention is recommended, not required, and a malformed block degrades the offline-resolution claim without invalidating the artifact. Under --strict the warning fails the gate.
