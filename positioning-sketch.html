The stack

Where useful AI chats currently die.

The substrate has already won — AI tools emit HTML by default. Live editing has tooling. Hosting has tooling. Discovery has tooling. The slot in between — seal — is where work goes after the chat closes but before it’s archived anywhere durable. That’s the missing layer. That’s where Capsule fits.

What it is

The sealed handoff format for AI work.

A Capsule is what a useful artifact becomes when work stops being actively edited — a frozen, portable, source-aware package for future use rather than ongoing mutation. The glossary names it directly: a sealed handoff format — the role capsules play after work stops being actively edited… Contrast with Canvas/Artifacts (the editing layer) and repos (the production layer).

One HTML file. Human-readable, machine-readable, and provenance-bearing in a single object. Same envelope whether an LLM, a build script, or a human authored it. Open the file in five years — it still renders, still carries its manifest, still names where it came from.

Evidence

The substrate has already won. The seal step is missing.

“I’ve started preferring HTML as an output format instead of Markdown.” Thariq Shihipar · Anthropic, on HTML as the new default for AI output
“If you want to create digital artifacts that last, they must be files you can control, in formats that are easy to retrieve and read.” Steph Ango (Kepano) · File over App

Convergent signal. htmlbin and MinDev independently reached the same hosting shape — short URL plus byte-identical /raw endpoint — working from the spec prose alone. The host-contract is a real pattern, not an invention.

What this is not

Defined by negation, in the project’s own words.

  • Not a new file format. It’s HTML.
  • Not a SaaS or product. No accounts, no server, no service.
  • Not a competitor to Canvas or Artifacts. They’re the editing layer; Capsule is the seal step that comes after.
  • Not anti-platform. Anti-context-loss.
  • Not a standard you have to comply with. A loose discipline.
  • Not finished. Active research.

The technical spine

What’s actually in a Capsule.

  • One .html file. No companion folders, no sidecar assets.
  • Five required inline blocks: capsule-manifest, capsule-data, capsule-style, capsule-root, capsule-runtime.
  • Manifest carries identity (UUID), provenance (generator kind), and capabilities.
  • Zero network. Works identically over file:// and http://.
  • Content is pre-rendered in the HTML — readable without JS.

Full contract: CAPSULE_CORE.md · implementer-grade detail: spec/CAPSULE_SPEC.md.
