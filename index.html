00b · case study

From Thariq's FAQ:

Maybe let's take it a step further.

When I'm doing my work — for example, creating JPEG/geospatial maps and reports for clients or colleagues — I've designed my map-making tool to emit HTML according to domain-specific logic that conforms to my HTML Capsule spec. That way they get exactly the thing they want and need: it's standalone (doesn't require maintaining a database or datasets), and it's permanent. And it's also HTML, so it's AI/LLM friendly.

Does the file size creep up? Yes — but frankly, I don't care. The tradeoff is worth it for me: I get a permanent object that doesn't require me to maintain a database. Plus, it can be used offline, by either me or them.

— Luke Schuss · maintainer · Vancouver · lukeschuss.com

09 / 09

Context-led · plain-English on-ramp

HTML you can keep.

AI tools increasingly produce HTML: reports, maps, demos, dashboards, visual notes, and interactive documents.

HTML Capsule is an open spec for saving that work as one self-contained .html file. A Capsule includes its own content, styles, metadata, provenance, and validation rules, with no required network access.

It is not a new file format. It is a stricter way to package HTML so the work can be archived, shared, inspected, and continued later — by humans, tools, and LLMs.

One file. No network. Built to last.
